# Self-hosting notes at freeze

Likecord has a local development Compose file and a separate image-based staging Compose file. Neither is a turnkey production security guarantee. The old [deployment plan](../deployment.md) contains historical cost/provider assumptions; use the current [staging Compose](../../docker-compose.staging.yml) and [runbook](../operations/staging-vps.md) to understand the implemented deployment shape.

The former Likecord GHCR packages were deleted after archival. For an Internet-facing fork, build and pin your own Web/API images, supply a DNS name and TLS, keep PostgreSQL/Redis off public interfaces, expose only the required Caddy and coturn ports, and provide distinct JWT, TURN, link-preview cache, database and optional R2 credentials from a private secret source. The staging template describes the variable names. Run Prisma migrations before first login, then use the compiled first-user CLI documented in the [bootstrap guide](../operations/staging-first-user-bootstrap.md). Do not use `apps/api/scripts/seed.ts` outside a disposable local database.

Voice and Screen Share need WebRTC connectivity testing on the target network. The API exchanges signaling; media is peer-to-peer or TURN-relayed. coturn requires its shared secret to match the API and its external IP/domain to be correct. Browser capture and output-device behavior vary by platform; the [freeze snapshot](../../PROJECT_STATUS.md) lists unresolved quality and lifecycle defects.

The local Compose includes a `backup` container, but its [script](../../docker/backup/script.sh) actively executes `pg_dump`; encryption and off-host upload commands remain commented out. The prototype does not certify successful scheduled backups or restoration. Set up encrypted database backups, off-host retention, restore drills, object-storage protection and monitoring separately before relying on an instance. The generalized runbook describes selective rollback and guarded recovery principles to adapt to the fork's own runtime. Historical candidate artifacts remain available through the [operations summary](../history/operations.md).
